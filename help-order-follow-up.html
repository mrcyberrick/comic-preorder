PULLLIST

Order Follow-Up: how to handle these

For store admins · Back to the dashboard

What this list is for

It shows reserved titles that need a decision, at the point where the decision still helps: before the order cutoff (At risk), after a missed cutoff (Backordered), after the on-sale date (Never arrived) and when a distributor withdraws a title (Withdrawn). Handle a row and it leaves the list. Your choice stays put; the weekly import does not undo it.

At risk

Reserved, not ordered, and the order cutoff (FOC) falls before this cycle's Order Deadline.

  • Going into this cycle's order? Mark Ordered. Customers see "Order placed".
  • The store won't stock it? Can't get it. Customers see "Not available — the store could not get this title." and can remove it.

Backordered

The order cutoff has passed and it was never ordered.

  • Ordered it late anyway? Mark Ordered.
  • Can't get it now? Can't get it (customers see the same message as above).

Never arrived

On sale, and no invoice line shows it came.

  1. Look on the shelf, in the boxes and on the counter. Invoices miss lines, and a book handed over the counter leaves no record.
  2. Then mark one:
    • Received: it is here. The reservation is marked fulfilled and customers see it as normal.
    • Didn't arrive: it never came. Customers see "No longer coming: the store already knows and handles it with the supplier" and cannot remove it. It stays there for 180 days from the on-sale date.
    • Damaged: it came damaged. Customers see the same, worded "Arrived damaged".
    • Rejected by supplier: the distributor refused the order. Shown only when an order is on record. Customers see "Rejected by the supplier — this title will not arrive as scheduled." and can remove it.

Turned up after all

You marked it Didn't arrive, then a later invoice listed it. It appears once, at the top of Never arrived. If it is here, mark Received so customers stop reading "No longer coming". If not, mark Didn't arrive (keep) and it will not come back for that invoice.

Withdrawn by the distributor

The distributor dropped the code, so it can no longer be ordered. Customers already see "Withdrawn — cannot be ordered" on My List and can remove it themselves.

  1. Check the distributor's site for the same book under a new code. If it is there, use Move reservations… to move everyone's reservation to the new listing.
  2. If a "⚠ already submitted" line shows, an order is on record for the old code. Confirm with the distributor, then Rejected by supplier to settle it.
  3. Acknowledge when you have read it or acted on it. It leaves the list and customers see no change. It comes back only if the title is marked withdrawn again or someone new reserves it.

Still finding out?

Use Snooze on an At risk, Backordered or Never arrived row: pick a date and add a note ("emailed PRH 11/9"). The row hides until that date, then comes back with your note if it is still open. Customers see nothing change. Show them lists snoozed rows; Wake now brings one back early.

Rows that clear themselves

A title that gets ordered, shows up on an invoice, has a supplier rejection recorded, or is withdrawn by the distributor (it moves to the Withdrawn panel).

Mistakes

Received, Didn't arrive and Damaged take effect at once and have no undo in the app. If you mark the wrong one, ask your PULLLIST operator to correct it. Can't get it and Rejected by supplier ask you to confirm first.

Customers are not emailed

They see these messages on My List.
